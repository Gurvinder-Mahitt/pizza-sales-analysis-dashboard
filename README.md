# pizza-sales-analysis-dashboard
nd-to-end pizza sales analytics project: ingested 48,620 POS records into MySQL, wrote 14+ SQL queries (KPIs, Pareto analysis, market basket co-occurrence), and built a 2-page interactive Power BI dashboard. Covers $817.86K revenue across 32 products, 4 categories &amp; 21,350 orders (2015 data).
